## Internship Task

### Task 1: Voice Assistant
Beginner Tier

## Project Description
This project is a Python-based voice assistant that listens to spoken commands and responds using text-to-speech.

## Features
- Captures voice input using the microphone
- Responds to "Hello" with a predefined greeting
- Provides the current time
- Provides the current date
- Performs Google web searches
- Opens Google and YouTube
- Provides voice feedback using pyttsx3
- Handles speech recognition errors gracefully
- Supports exit commands such as "exit", "quit", and "stop"

## Technologies Used
- Python
- SpeechRecognition
- PyAudio
- pyttsx3
- datetime
- webbrowser

## Installation
1. Clone the repository.
2. Open the Task 1 folder in VS Code.
3. Create and activate a virtual environment.
4. Install the required packages:

    pip install -r requirements.txt

## How to Run

Run the following command:

    python main.py

Allow microphone access and speak a command.

## Example Commands
- "Hello"
- "What is the time?"
- "What is the date?"
- "Search Python programming"
- "Open YouTube"
- "Open Google"
- "Exit"
